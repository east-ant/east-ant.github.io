Projects

TRAVELY — AI 여행 일기 자동 생성 및 포토프린터 출력 서비스

2025.11 – 2026.01 · 3인 팀 · 프론트엔드 전체 + AI 기능 담당 · 대한임베디드공학회 2026 추계학술대회 포스터 발표

사진을 올리면 멀티모달 LLM이 키워드와 일기를 생성하고, 레이아웃 편집 후 라즈베리파이 포토프린터로 실물 출력까지 이어지는 웹 서비스.

주요 역할

  • Next.js 15 / React / TypeScript로 업로드 → AI 생성 → 편집 → 출력의 6단계 플로우 설계·구현
  • GPT-4o-mini 프롬프트 설계: 사진 유형별 감정 키워드 추출, "문단 수 = 사진 수" 제약으로 사진–문단 1:1 매핑, 문체 통일 규칙
  • EXIF 촬영시각·GPS 추출 → 시간순 자동 정렬 및 Kakao 역지오코딩 장소명 표시
  • 스티커 드래그·리사이즈 편집기 및 html2canvas 기반 인쇄용 이미지 렌더링 구현

해결한 문제

  • 편집 화면과 출력물의 색상·배경 줄무늬·페이지 분할이 어긋나는 문제 해결 — Tailwind v4의 oklch 색상을 캡처 전 RGB로 치환하고, 줄무늬는 CSS 대신 canvas에 직접 그리며, 페이지를 개별 캡처하도록 파이프라인 재설계

배운 점

  • 렌더링 라이브러리 한계에 부딪혔을 때 CSS를 고치기보다 출력 단계에서 직접 그리는 우회 판단
  • 구두 합의로 API를 맞추다 방어 코드가 늘어난 경험에서, 인터페이스는 명세 문서로 먼저 고정해야 함을 체감
